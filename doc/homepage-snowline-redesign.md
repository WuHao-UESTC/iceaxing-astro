## 1. 设计结论

首页继续采用四个完整视口章节：封面、技术栈、生活日常、沿途随记。整体视觉围绕 **Snowline / 雪线** 展开，但不使用写实雪山照片或复杂插画，而是以抽象雪脊、等高线、海拔标记和大面积留白建立现代、简约的个人博客形象。

第一版设计名为 **「静默雪线 / Quiet Snowline」**。核心感受应是：冷静、开阔、克制，同时保留个人表达的温度。

### V2 调整摘要

- 四屏右上角统一增加大号章节编号、海拔和场景英文名；移动端压缩为左右分列的路线标记。
- 封面主标题统一为 `ICEAXING`，简介和座右铭降为辅助信息。
- 三个章节入口取消卡片边框，改为沿右侧上升雪脊布置的路线节点；悬停、聚焦时只增强节点和方向箭头。
- 四屏统一采用“章节标题 + 编目线 + 内容行”的排版语法，移除技术页和随记页中不协调的卡片容器。
- 生活日常没有分类时不渲染空路线区，近期内容自动扩展为完整宽度；后续加入 `group: life` 分类后自动恢复双区布局。

### V3 背景方案：四种海拔场景

V3 不再把背景作为一张单薄的山形底图，而是用三层景深、环境线索和路线痕迹区分四个章节。所有背景均由 Astro 内联 SVG 与 CSS 色彩变量生成，不增加图片下载、客户端组件或动画依赖。

| 章节        | 场景表达 | 背景元素                                                   |
| ----------- | -------- | ---------------------------------------------------------- |
| 01 封面     | 高山启程 | 远中近三层山体、峰面切片、日轮、风线、等高线与登山路径     |
| 02 技术栈   | 岩脊测绘 | 陡峭岩层、地质层理、坐标网格、十字测量点与虚线攀登路线     |
| 03 生活日常 | 风积雪原 | 低位太阳、横向风线、多层雪丘、柔和等高线与穿越雪地的足迹   |
| 04 沿途随记 | 星夜营地 | 疏朗星点、星座连线、月影、围合山谷、回营路线与极简帐篷光晕 |

背景的统一规则：

- 山体始终使用低对比色块，正文与交互元素保持在更高层级。
- 主轮廓使用 Snowline 强调色，等高线、网格、风线和星图降低至辅助透明度。
- 装饰优先进入标题、列表之间的留白区，不横穿长段正文。
- 浅色主题表现为冰雪测绘图，深色主题表现为墨绿山夜；不为主题切换加载另一套素材。
- 手机端降低整体 SVG 透明度并裁切远景，保留主山脊、路线和最具识别度的场景元素。

### V4 色彩与灵动元素

V4 在不改变 Snowline 冷静基调的前提下加入“高山晨昏色谱”。色彩只用于路线、章码、环境光和小型叙事元素，正文、山体主体和大面积页面背景继续保持中性，以降低长时间阅读的视觉疲劳。

| 色彩     | 浅色主题  | 主要用途                           |
| -------- | --------- | ---------------------------------- |
| 冰川蓝   | `#176B8D` | 技术栈、冰面轮廓                   |
| 晨曦珊瑚 | `#A63F2F` | 封面、峰顶旗帜、精选文章箭头       |
| 日光金   | `#7D5600` | 生活日常、太阳、雪原路径节点       |
| 高山苔绿 | `#527A61` | 雪原足迹和自然细节                 |
| 夜幕紫   | `#58458D` | 沿途随记、星图、月影和夜间章节节点 |

深色主题使用同一色相的提亮版本，保证深色背景上的辨识度。封面 `ICEAXING` 仅在末端过渡到珊瑚与日光金，其余文字仍保持主文字色。

灵动元素包括：

- 封面山顶增加小型晨曦旗帜，三个章节入口使用不同颜色的路线节点。
- 生活日常增加缓慢漂移的冰晶和双色足迹。
- 沿途随记的星点以不同节奏轻微闪烁，帐篷使用珊瑚与暖金光晕。
- 测绘路线使用极慢的虚线流动，路线节点只做小幅呼吸变化。
- 每个章节加入低透明环境柔光，并进行幅度很小的缓慢位移。
- `prefers-reduced-motion: reduce` 下关闭全部连续背景动画，仅保留静态色彩和场景图形。

### V5 视觉收束与封面路线校准

V5 对 V4 的多色方案进行收束，解决不同色彩同时出现造成的杂乱感，并修正封面标题在中间缩放区间被双栏挤压的问题。

#### 统一背景与章节单色

- 四个章节统一使用相同的冷白／墨绿中性渐变底色和中性环境柔光。
- 每屏只使用一个章节主色：封面为晨曦珊瑚、技术栈为冰川蓝、生活日常为日光金、沿途随记为夜幕紫。
- 山体轮廓、章码、眉题、路径、节点、进度线和场景小元素全部继承当前章节主色。
- 右侧章节导航仅让当前节点显示章节色，未选节点保持中性，避免四种颜色同时抢占视线。
- V4 中双色足迹、双色项目进度线和彩色营地光晕改为当前章节单色的透明度变化。

#### ICEAXING 标题适配

- 标题字号改为基于标题容器宽度的 `cqi` 单位计算，而不是仅依赖视口宽度。
- 桌面双栏、中间宽度、手机和浏览器缩放时，标题始终限制在左侧内容栏内。
- 保留不换行和末端珊瑚渐变，但取消第二种装饰色。

#### 封面章节入口

- 三个入口统一放大节点、编号和章节名称，提高入口识别度。
- 路线缩短到背景山峰左侧，入口从山脚到峰顶依次排列，不再越过峰顶进入右侧章码区域。
- 三个节点与同一条上升曲线紧密贴合，并与背景主山脊的上升方向保持一致。
- 桌面入口保持在标题栏右侧；手机端入口位于简介和精选文章之间，不遮挡标题、简介和格言。

### V6 封面信息流与导航调整

- 封面左侧形成“标题与简介 → 认识我 → 精选文章”的连续纵向阅读流；精选文章改为单列编目，不再横跨页面底部。
- 技术栈、生活日常、沿途随记三个入口从山脊节点改为封面底部横向等分导航；保留圆点、编号与轻量顶线反馈，不形成厚重按钮框。
- 顶部导航新增“技术栈”和“生活日常”，分别直达首页的 `#technical-ridge` 与 `#snowfield-traverse`，并同步提供中、英、德文案。
- 四屏继续共用同一中性背景，章节强调色整体加深；色彩只属于当前章节，不恢复多色混用。
- 封面文案列显式设置响应式宽度，避免容器查询在 flex 布局中按最小内容宽度收缩。

本轮遵守以下边界：

- 技术栈、生活日常、沿途随记三个章节的数据来源、内容类型、排序和展示数量暂时不变。
- 首页仍为四屏纵向浏览，不增加第五屏或额外信息架构。
- 使用 Astro 构建期渲染、语义化 HTML、原生 CSS 和现有轻量脚本；不新增 React 首页组件、滚动动画库或 WebGL。
- 视觉素材优先使用站内 SVG 与 CSS 绘制，首版不依赖外部图片资源。
- 保留浅色、深色主题及中、英、德三种语言。

## 2. 视觉语言

### 2.1 Snowline 的表达方式

雪线不是单一背景插画，而是贯穿四屏的视觉语法：

1. 一条主雪脊线负责划分空间，并引导视线向下一章节移动。
2. 一至两条低对比等高线提供海拔与地形感，不穿过正文。
3. 章节编号与海拔值作为信息标记，而不是纯装饰。
4. 山体只使用大色面和细线，不使用拟真纹理、阴影堆叠或卡通图形。
5. 每屏的雪脊走势不同，但线宽、颜色和节点规则保持一致。

四屏的地形节奏：

| 章节        | 地形语言                                       | 视觉感受           |
| ----------- | ---------------------------------------------- | ------------------ |
| 01 封面     | 从左下向右上延伸的平缓主雪脊，右侧形成开阔峰面 | 出发、留白、方向感 |
| 02 技术栈   | 收拢、较陡的上升折线和少量路径节点             | 精确、工程感、进展 |
| 03 生活日常 | 横向舒展的低坡雪线，节点间距更松               | 开阔、轻松、呼吸感 |
| 04 沿途随记 | 低处围合的山谷轮廓与一个安静光点               | 停驻、回望、收束   |

### 2.2 色彩

沿用现站青绿色品牌倾向，把颜色调整得更冷、更安静。首页使用自身的 snowline 语义变量，但与全站基础变量保持映射，避免形成两套互不相关的主题。

| 用途           | 浅色主题       | 深色主题           |
| -------------- | -------------- | ------------------ |
| 页面背景       | `#F5F7F6` 冷白 | `#0D1211` 深墨绿黑 |
| 内容表面       | `#FFFFFF`      | `#151C1A`          |
| 主文字         | `#172220`      | `#EAF0ED`          |
| 次要文字       | `#687471`      | `#9EACA7`          |
| 主雪线／交互色 | `#2E7168`      | `#8EC9BC`          |
| 低对比山体     | `#E3EBE8`      | `#202B28`          |
| 分隔线         | `#D9E1DE`      | `#33413D`          |

强调色只用于当前章节、按钮状态、海拔节点和少量关键词。大面积区域保持中性色，避免整屏泛绿。

### 2.3 字体与排版

- 品牌、导航、按钮、日期和海拔使用系统无衬线字体，保持清晰和现代感。
- 章节大标题可使用现有阅读衬线字体；若中文衬线字体在不同系统表现不稳定，则统一回退到系统无衬线字体，不额外加载大型字体文件。
- 封面标题桌面约为 `clamp(4rem, 8vw, 8rem)`，手机约为 `clamp(3rem, 16vw, 5rem)`。
- 正文与说明保持 16–18px，导航不低于 14px。
- 采用紧凑标题字距、舒展段落行距；用间距和细分隔线组织信息，减少卡片阴影与厚重圆角。

### 2.4 组件形态

- 主按钮：实色或反色表面，直角与轻微圆角之间取克制值，建议 6px。
- 次按钮：透明底、细边框，悬停时只改变边框、文字和一个方向箭头。
- 内容卡片：尽量表现为列表、分栏和细分隔线，不做悬浮大卡片墙。
- 模糊背景只用于顶部导航等确有叠层需求的位置，不在所有内容表面重复使用。
- 阴影只用于浮层和移动菜单，首页主体依靠层次色与留白区分。

## 3. 四屏总体框架

顶部导航固定在视口上方。首页主体高度使用 `100dvh - 导航高度` 计算，每个章节至少占满一屏。

桌面端保留右侧章节导航，以四个节点展示：

```text
3200m  封面
4200m  技术栈
5100m  生活日常
6200m  沿途随记
```

当前节点为实心，其他节点为空心；只有当前项和悬停项展开文字。手机端改为底部紧凑的四节点控制，不覆盖正文链接。

滚动以浏览器原生滚动为基础，只在章节边界补充吸附：

- 常规桌面根据滚轮幅度一次推进/退回一至多个章节；短视口、横屏手机、文字放大或内容溢出时，先允许章节内部自然滚动，抵达边界后再翻章。
- 章节内部可滚动区域优先消费滚轮，抵达其边界后才交还给章节导航，避免滚轮被吞掉。
- 触摸设备保留原生吸附；内容高于视口时自动降级为接近式吸附。
- 章节锚点保持为 `#base-camp`、`#technical-ridge`、`#snowfield-traverse`、`#night-camp`。
- 无 JavaScript 时仍可自然滚动和使用所有锚点链接。

## 4. 封面设计

### 4.1 页面目标

封面应在一个视口内完成三件事：

1. 说明站点是谁以及写什么。
2. 建立 Snowline 的第一视觉印象。
3. 让访客无需滚动试探，就能直接选择技术栈、生活日常或沿途随记。

### 4.2 桌面构图

封面采用不对称构图。左侧集中放置站点标题、简介、座右铭、个人档案入口和纵向精选文章；右侧保留抽象雪山与峰顶标记作为留白背景。三个章节入口独立沉到封面底部并横向等分，使内容阅读与页面导航互不争抢。

```text
┌──────────────────────── 顶部导航 ────────────────────────┐
│                                                          │
│  PERSONAL FIELD NOTES                       01 / 3200m   │
│                                                          │
│  ICEAXING                             峰顶 / 主雪脊      │
│  一段简短介绍与座右铭                                    │
│  认识我 →                                                 │
│  精选文章                                                 │
│    01 日期 / 标题                                         │
│                                                          │
│  ○ 02 技术栈     ○ 03 生活日常     ○ 04 沿途随记        │
└──────────────────────────────────────────────────────────┘
```

### 4.3 三个章节按钮

新增三个明确的页内跳转按钮：

- `02 / 技术栈` → `#technical-ridge`
- `03 / 生活日常` → `#snowfield-traverse`
- `04 / 沿途随记` → `#night-camp`

路线入口的设计规则：

- 桌面端在封面底部横向等分展示，编号和标题始终可见，不使用矩形外框与常驻填充底色。
- 三个入口完全等权；圆形节点、章节编号和方向箭头承担交互反馈，悬停后对应节点增强。
- 键盘聚焦状态与悬停状态具有同等清晰度。
- 点击后使用现有章节导航能力平滑移动；开启减少动态效果时立即定位。
- 手机端仍保持三列横排，并压缩为“节点与编号在上、标题在下”的两行结构，不使用横向滚动。

### 4.4 封面其他内容

第一版暂时保留现有标题、简介、座右铭和精选文章，但重新分配主次：

- 三个章节按钮成为封面底部的首要行动区。
- “精选文章”紧跟“认识我”下方，使用纵向低矮文字列表；不再横跨整个页面，也不使用高卡片抢占主视觉。
- “认识我”不再作为封面主按钮，因为“个人档案”会进入全局顶部导航；可作为简介末尾的低调文字链接保留。
- 低视口高度允许封面内容自然超过一屏，并降级为接近式吸附，不裁切精选文章或交互入口。

### 4.5 移动端

手机封面按以下顺序单列排布：

1. 章节编号、海拔和英文场景名。
2. 主标题、简介和座右铭。
3. “认识我”与纵向精选文章列表。
4. 底部横排的三个章节入口。
5. 底部章节节点导航。

雪脊退到内容右下方，透明度降低，不与文字重叠。标题、入口和焦点状态优先于装饰完整度。

## 5. 技术栈、生活日常、沿途随记

本轮只重构三个章节的外观容器，不改动其展示内容。

### 5.1 技术栈

- 继续展示 `group: skill` 的分类入口和当前项目。
- 保留左侧分类路线、右侧项目列表的桌面结构。
- 分类编号与项目进度线使用统一的雪线强调色。
- 项目区去掉不必要的半透明卡片感，改为更清楚的分隔线列表。
- 数据来源、排序、项目状态和展示数量不变。

## 6. 顶部导航

### 6.1 桌面导航

在现有导航基础上补齐首页章节入口、个人档案和友链。完整顺序为：

```text
首页 / 技术栈 / 生活日常 / 文章 / 项目 / 工具 / 关于 / 个人档案 / 友链
```

左侧为 `iceaxing.` 品牌，中间为主导航，右侧保留搜索、语言与主题切换。

视觉规则：

- 导航高度维持约 64px，使用低透明冷白／深墨背景和轻量模糊。
- 当前页面通过文字颜色与底部短线共同表示，不只依赖颜色。
- 导航文字使用中等字重，悬停不产生位移。
- “技术栈”和“生活日常”直达当前语言首页的章节锚点；“个人档案”链接到 `/profile`，“友链”链接到 `/friends`；三语路径继续由现有 `localizedPath` 生成。

### 6.2 中小屏导航

九个文字入口在中等宽度下不应被强行压缩。建议在约 1024px 以下切换为原生 `<details>` 菜单：

- 品牌保持在左侧。
- 搜索、语言、主题切换保留为直接操作。
- 菜单内完整展示九个导航入口，不隐藏“技术栈”“生活日常”“个人档案”与“友链”。
- 菜单使用语义化结构和少量原生脚本处理 Escape、焦点恢复及路由切换关闭；不引入菜单组件库。

## 7. 动效

动效的作用是提示路径与层级，不制造“炫技”感。

- 每个章节首次进入时，雪脊线在 500–700ms 内轻微显现，正文随后以 8–12px 位移淡入。
- 单屏完整入场控制在 800ms 左右，不逐字播放，不使用大范围模糊和缩放。
- 已访问章节再次进入时保持内容可见，仅更新章节节点。
- 按钮悬停只改变边框、底色、箭头位置 2–4px，以及对应路径节点强度。
- 主题切换不重播章节动画。
- `prefers-reduced-motion: reduce` 下关闭描线、位移和程序化平滑滚动。

## 8. 响应式与无障碍

- 以 1440×900 和 1366×768 为主要桌面基准，同时验证 1024px 平板、390px 与 320px 手机。
- 在 200% 缩放、低高度和德语长文本下，章节允许超过一屏；不得通过裁切文字维持形式上的全屏。
- 页面整体不出现横向滚动，装饰 SVG 使用 `aria-hidden="true"`。
- 所有章节标题可被锚点定位并获得清晰焦点。
- 所有按钮、导航和卡片均支持键盘操作，焦点环对浅深主题都有足够对比度。
- 不以动效、颜色或节点形状作为唯一信息来源。
- 无脚本时不隐藏任何内容，四个章节仍按普通文档顺序可读。

## 9. Astro 实现原则

设计落地时保持现有 Astro 架构：

- `HomePage.astro` 在构建期完成内容查询、分类分组和卡片数据准备。
- 四个章节继续拆分为独立 `.astro` 组件，不转换为 React island。
- 山体与雪线使用复用的 Astro SVG 组件，通过 `scene` 和 CSS 变量改变构图。
- 页内跳转使用真实 `<a href="#...">`，现有 `home-journey.ts` 只负责渐进增强、当前章节状态和可选的平滑定位。
- 章节检测使用一个 `IntersectionObserver`，不增加滚动监听库。
- 响应式、主题和大部分交互状态由 CSS 完成。
- 顶部移动菜单优先使用 `<details>`；仅在焦点管理确有需要时补充极少脚本。
- 不新增运行时数据请求，首页内容仍随 Astro 构建生成。
