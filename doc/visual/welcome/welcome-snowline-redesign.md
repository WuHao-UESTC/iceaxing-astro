# 欢迎页设计方案 V1：雪线起点

日期：2026-11-02。状态：已在本地实施（2026-11-02），未发布线上。以下保留原方案；实际状态见 [实施记录](../../engineering/snowline-refactor-implementation.md)。

配套：[首页 V8](../homepage/homepage-snowline-redesign.md)、[工作留痕](../../discussion_record/snowline-redesign-change-log.md)。

## 1. 页面目标与建议文案

根路径欢迎页负责介绍作者并分流到「个人简历」「博客首页」，与 `/blog` 五章首页分工明确，不把四板块和文章列表全部塞进欢迎页。

主题为「雪线起点」：白天收到双色印刷的远征邀请，夜里走进温暖的高山观测站。以连续山脊、雪面、路线和营地延续「雪线之上」，全面替换 low-poly 地形。

页面从上到下：

1. 页头：ICEAXING 与简化雪峰标识；右侧保留语言与主题切换。
2. 作者行：真实头像、姓名与「你好，我是 Iceaxing。欢迎来访。」资料继续读取当前来源。
3. 主标题：「很高兴，在雪线之上遇见你。」副题：「每一段探索，都从一次相遇开始。」
4. 引言：「一边是我的经历，一边是沿途的记录。选一条感兴趣的路，我们慢慢认识。」
5. 两个入口：「看看我的个人简历」——「经历、方向与项目，认识我正在做的事。」；「逛逛我的博客」——「技术栈、学习笔记、生活日常，以及沿途随记。」
6. 页脚：「不必赶路，随意逛逛。」配「BASE CAMP / 旅程的起点」。

以上为中文建议文案，中英德以自然表达保持同意，允许标题换行。地点沿用真实配置，不新增虚构海拔、天气、坐标或在线指示。英文仪表标签只是辅助，不能替代中文操作名称。

## 2. 桌面版式

以 1440 × 900 为参考，容器约 1280px、边缘留白 40–64px。页头约 80px。主体左侧约 55% 为问候、主标题与双入口，右侧约 45% 为雪峰插画，底部小字收尾。低高度窗口允许自然滚动，不锁定一屏。

标题分两行，中文约 52–68px，正文约 17–18px、行高约 1.7。两个入口并排且视觉权重相近，用「01 / 认识我」「02 / 开始探索」区分；都有标题、说明与箭头。整个入口是一个语义链接，不嵌套按钮。

右图是一座有长山脊和明确雪线的主峰，路线从营地延伸向雪线，山脚分为「个人经历」「沿途记录」两条路径。两条路不暗示内容高低优劣。悬停或键盘聚焦时，对应短段路线增强；图形不承担唯一导航功能。

## 3. 浅色：双色远征邀请

参考 [04 双色网点刊物](../../prototypes/style-atlas/04-riso.html)。暖纸底 `#F3E9CE`，深蓝 `#243B68` 为文字，朱红 `#D24F3F` 为图形与入口强调，与首页共享色系。

页头像刊头，但主标题仍为欢迎语，ICEAXING 不挤占整页。左右栏用细蓝线建立版心；双入口像两张索引页，直角、细边框、小题签，悬停用局部浅红底和箭头反馈，不做整卡倾斜。

插画以蓝色网点岩壁、纸白雪冠、朱红路线和小太阳构成。套印偏移仅在装饰边缘约 1–2px，文字与控件清晰。纸感轻微，文字区不铺高频噪点；头像保留原色。双色指两种墨加纸底，不强制将真实照片双色化。

## 4. 深色：营地观测站

参考 [15 复古未来终端](../../prototypes/style-atlas/15-terminal.html)。暗绿黑 `#151C1C` 为底，暖浅色 `#E0C79A` 为文字，琥珀 `#DCA66B` 为操作与轮廓。内容顺序和入口位置与浅色一致。

页头像仪表铭牌，中文标题与正文清晰无衬线，英文编号等宽。双入口为带角标的硬边分舱，明确标「个人简历」「博客」，不要求输入命令，不等待启动动画后才可进入。

山图转为琥珀山脊轮廓、等高线和路线剖面；营地是一个稳定小亮点。暖光仅给少数节点与角标，不给正文发光，不用宇宙轨道替代山峰。静态扫描纹理如保留，只限插画分舱。

## 5. 手机与小屏

768px 以下单列：页头 → 作者行 → 标题引言 → 两个入口 → 简化山图 → 页脚。390px 下留白约 20px，320px 下页头动作可适度换行。入口纵排、文字完整，不用横向滑动才能发现第二入口。

主标题约 34–42px，按语言长度调整。山图压缩为约 160–200px 高的横向山脊；屏幕高度不足时自然滚动，不缩小文字或裁掉入口来凑一屏。触屏用底色、边框与按压状态提供反馈，不依赖 hover。主题切换保持布局、焦点和语言。

## 6. 动画分镜

| 阶段 / 触发 | 浅色 | 深色 | 约束 |
| --- | --- | --- | --- |
| 首屏 0–180ms | 刊头与作者行淡入 | 铭牌与作者行淡入 | 内容与链接已存在，立即可操作 |
| 首屏 80–400ms | 欢迎标题上移 8px 淡入 | 标题淡入，边线展开 | 不逐字打印、不闪烁 |
| 首屏 180–600ms | 网点显现，朱红路线短段绘出 | 插画内部一次扫描揭示，路线显现 | 不扫正文、无声、无强光 |
| 首屏 200–500ms | 双入口错开 50ms 轻移入 | 分舱角标与文字淡入 | 两入口始终可点击 |
| 悬停 / 聚焦 | 下划线及路线增强，箭头右移 3px | 边框和对应路线提亮 | 120–180ms，静态焦点框立即出现 |
| 点击 | 简短按压反馈，正常导航 | 同样行为 | 不增加等待、不做离场锁屏 |
| 主题切换 | 色彩和图形材质交叉淡入 | 反向同理 | 180–240ms，不重置状态 |

首屏整组不超过 650ms，仅一次；不持续飘雪、循环扫屏或模拟加载日志。连续操作中止上一段反馈，以最新状态为准。减少动态效果时全部直接出现，取消平移、描线、扫描和主题转场；离屏停止装饰动画。

## 7. 功能与审阅边界

保留双入口、真实资料、中英德与主题持久化，以及旧首页锚点导向 `/blog` 并保留参数的逻辑。不强迫选主题，不根据访问次数自动跳过欢迎页，返回时不重复强制演出。普通链接支持新标签打开，装饰图不进入键盘顺序，真实标题文字不烘焙成图像。

正文对比度至少 4.5:1，大字与必要非文字控件至少 3:1；触控目标建议至少 44px。后续验证桌面、平板、390px / 320px、中英德、200% 缩放、键盘、触屏及减少动态效果。此为验收要求，尚未做页面实现与运行验证。

建议审阅主标题是否采用本版雪线表达、双入口是否清楚、昼夜山图是否统一且有辨识度。推荐左文右图、手机入口优先；方向确认后再进入视觉稿和代码阶段。
