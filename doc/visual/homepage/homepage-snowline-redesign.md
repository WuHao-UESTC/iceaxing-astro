# 首页设计方案 V8：雪线远征刊物 / 高山观测终端

日期：2026-11-02。状态：V8 已在本地实施（2026-11-02），未发布线上。实现与检查见 [实施记录](../../engineering/snowline-refactor-implementation.md)。

本文替换 V7 成为当前首页视觉方案入口。旧稿原样保存在 [V7 归档](../../archive/2026-11-02/homepage-snowline-redesign-v7.md)。配套：[欢迎页方案](../welcome/welcome-snowline-redesign.md)、[工作留痕与功能表](../../discussion_record/snowline-redesign-change-log.md)。以下保留设计方案原文；实际实施状态以实施记录为准。

## 1. 核心方向

保留「雪线之上」与 ICEAXING，把整站想象成一份持续更新的个人登山记录：白天摊开双色印刷的远征刊物，夜里打开营地的观测终端。内容仍是技术、学习、日常与思考，攀登是串联内容的叙事线索。

浅色参考 [04 双色网点刊物](../../prototypes/style-atlas/04-riso.html)，深色参考 [15 复古未来终端](../../prototypes/style-atlas/15-terminal.html)。继承其美术语言，将参考稿中的抽象几何与宇宙轨道重新设计为雪峰、雪线、行进路线、测绘剖面和高山通信图形。

完全停止沿用 low-poly 三角面山体、折面明暗、切片地形与多边形景深。山的辨识来自连续山脊、岩层纹理、留白雪面和等高线。网点只参与插画与局部装饰，不给整页套纹理滤镜。

## 2. 昼夜统一视觉规范

| 项目   | 浅色：雪线远征刊物                | 深色：高山观测终端                   |
| ---- | ------------------------ | --------------------------- |
| 底色   | 暖纸 `#F3E9CE`，正文面干净       | 暗绿黑 `#151C1C`，分舱面 `#101A19` |
| 主文字  | 深蓝墨 `#243B68`            | 暖浅色 `#E0C79A`               |
| 强调   | 朱红 `#D24F3F`，用于路线、印章、大按钮 | 琥珀 `#DCA66B`，用于操作、刻度及选中状态   |
| 山岳图形 | 蓝色网点岩壁、纸白雪冠、朱红路线         | 连续矢量山脊、等高线、测绘剖面与信号轨迹        |
| 容器   | 编辑式分栏、粗标题线、栏目题签、直角       | 硬边分舱、角标、编号、稀疏刻度、直角          |
| 排版   | 中文大标题宋体风格，英文衬线刊头，正文无衬线   | 中文标题与正文清晰无衬线，英文和编号等宽        |

两种模式共享内容顺序、操作位置、选中状态和路由。主题切换允许材质与局部边界变化，不移动文章、不重置教材、分组或阅读位置。四板块依靠布局、图形和编号区分，不再各自使用一套彩虹配色。

双色指蓝、红两种印刷墨加纸底；真实照片、头像、证书和文章图片保持原色。小号文字使用主文字色，朱红优先用于大色块及非文字装饰。实施时须测量白字按钮、辅助字和边框对比度，不能将参考色值直接视为合格结果。正文不覆盖网点、扫描线或光晕。

## 3. 信息架构与浏览节奏

根路径继续是欢迎页，首页继续位于 `/blog` 及其多语言版本。顺序为封面、技术栈、学习笔记、生活日常、沿途随记。保留章节式浏览，改为连续阅读：桌面每章接近一屏，内容多时自然延长，不为凑齐一屏裁掉内容。

顶部第一行是品牌、全站导航、搜索、语言与主题；第二行为封面及四板块的章节目录。浅色像刊物栏目索引，深色像五路仪表标签。离开封面后第二行收紧吸顶，避免再叠加一套占位侧栏。全站原有工具、关于、简历、友链等导航入口均保留。

保留 `#base-camp`、`#technical-ridge`、`#study-terrace`、`#snowfield-traverse`、`#night-camp`、`#selected-notes`、`#hero-featured-list`。旧根路径锚点仍转向博客对应位置并保留查询参数。章间提供上一章、下一章与回到封面；普通滚轮、触摸保持原生滚动，不自动翻章。直接链接、浏览器前进后退及键盘导航继续有效。

## 4. 封面：远征总览

1440px 参考宽度下，内容宽约 1280px，左右留白至少 40px。「ICEAXING」跨栏刊头，下附「雪线之上 / ABOVE THE SNOWLINE」。正文区左侧约 45% 为内容，右侧约 55% 为雪峰主图。

左栏依次呈现作者简介、现有座右铭与来源、主操作「开始探索」、个人简历 / 全部文章 / 项目归档入口、精选文章。精选保留手动前后切换、序号和文章打开，不自动轮播。右栏山岳主图下列出四板块文字入口及一句说明；山图热点不能替代文字导航。现有推荐目的地继续可达。

建议封面短句：「循着好奇，向雪线之上。」简介和座右铭继续读取现有来源，不硬编码覆盖作者介绍，不虚构署名。

浅色像远征期刊封面：深蓝刊头与粗横线，网点岩壁和留白雪冠构成主峰，朱红路线串起四个编号路标；精选是「本期选读」栏目，展示真实日期和摘要。深色将同一山形转换为琥珀测绘轮廓与高度剖面，精选成为日志窗。雪峰是主体，不能退化成通用飞船控制台；不显示虚构天气、海拔实测值、在线人数或通信质量。

手机顺序：标题简介 → 主操作 → 四板块两列目录 → 简化山图 → 精选。山图约 160–220px 高。刊头流式缩放，英语和德语长词允许合理换行，不强塞一行。所有内容自然滚动。

## 5. 技术栈：岩脊工坊

主题：「把想法，一步步做成现实。」左栏技术分类与专题目录，右栏实际项目进展，保留所有内容入口、项目名、状态、百分比和项目路由。实践项目与教材继续按现有分类规则区分。

浅色像工程专题跨页：分类题签、项目表、刻度进度线与红色终点，角落用网点岩层剖面呼应岩脊。深色像实验记录台：分类和项目分舱，进度保持真实，不伪装为实时仪表。进行中与已完成有文字标签，不能只用颜色区别。

数量多时自然延长；手机先分类后项目。项目名、状态与链接优先，不把整张表缩小到难以阅读。

## 6. 学习笔记：高山星图与教材索引

主题：「把读过的书，整理成继续向上的路。」保留现有教材星图语义与交互：查看全景、选择教材、聚焦星区、阅读对应文章、返回全景，以及近期整理、笔记计数与空状态。教材继续是分类，不重新改回项目。

浅色画成远征队的天文观测插页：蓝色星点和细连线、红色选中括号、边缘少量网点山影。深色像夜间观测屏：琥珀星点、细线和选中框，取消随机闪烁。默认同时提供可操作的教材名称索引，键盘和小屏用户不必精准点击星点。

选中后桌面左侧保留星区，右侧呈现教材名、计数和文章列表；再次选中不重复启动长动画。手机教材索引在上、文章在下，星图作辅助。减少动态效果时直接切换状态，不能丢失选择与返回功能。

## 7. 生活日常：雪原散页

主题：「在寻常日子里，收集世界的细节。」保留生活分组、切换、近期文章与分类入口，继续与随记保持现有数据归属规则。

浅色像刊物生活版：横向栏目题签、一篇主推配真实图片、其余文章为短条，留白中点缀网点雪丘。深色像营地生活档案：照片置于带日期和栏目标签的记录窗，保留原色，减少刻度密度。

两种模式内容顺序相同；主推取当前分组现有排序的首项，不新增独立推荐规则。有分类正常切换，无分类则铺开近期内容；无文章给出真实空提示及有效入口。手机单列，图片比例稳定，不用统一裁切损失主体。

## 8. 沿途随记：山间驿站

主题：「短暂停靠，再继续出发。」保留碎碎念、时间顺序、展开与全文入口，以及关于、朋友、工具等站内目的地。顶栏随记归档与首页章节锚点都继续可达。

浅色像刊物末页短讯与沿途地址簿：日期窄栏、正文主栏，以细路线连接节点。深色像营地通信日志：安静日志窗与清晰的站内入口面板。保留真实原文和日期，不添加模拟聊天、随机输出或永远滚动的命令行。

用户主动展开长记，可收起或进入正文，不逐字打印。结尾提供回到封面、RSS 与友链；订阅沿用既有位置与完整流程。

## 9. 动画方案

浅色像纸面排版展开，深色像仪器画面建立。只做一次清楚揭示与轻量反馈，不播放强制片头、不等待正文打字、不绑架滚动。

| 触发 | 浅色 | 深色 | 时长与边界 |
| --- | --- | --- | --- |
| 首次封面 | 标题上移 8px 淡入，分栏线展开，网点由淡到实 | 标题先显现，山图一次局部扫描揭示，随后显现刻度 | 单元素 240–400ms，错开 50ms，整组不超 700ms；按钮立即可用 |
| 章节入视口 | 题签上移 8px，短段路线绘出 | 分舱边线与标题淡入，章节指示更新 | 240–360ms，每章首次一次，回滚不反复隐藏 |
| 点击章目录 | 平滑定位，当前栏红底或下划线更新 | 同样定位，当前栏琥珀边框更新 | 约 300–450ms；连续点击以最后目标为准 |
| 悬停 / 聚焦 | 下划线展开、箭头右移 3px | 局部底色和边框轻微提亮 | 120–180ms，焦点框立即可见 |
| 精选换页 | 原位置平移 10px 淡入 | 短淡入，序号同步更新 | 180–240ms，预留高度，焦点不跳动 |
| 选择教材 | 星区平移聚焦，文章栏淡入 | 选中框移动，星区同样聚焦 | 280–360ms，保留状态及返回全景 |
| 生活分组 | 内容短淡入 | 内容短淡入，题签更新 | 160–220ms，避免高度跳动 |
| 随记展开 | 内容区展开，日期与标题原位 | 同样展开，边线略提亮 | 180–240ms，不模糊或逐字呈现正文 |
| 主题切换 | 底色、墨色、图形材质交叉淡入 | 反向同理 | 180–240ms，布局、焦点和状态稳定 |

深色扫描限于插画，不扫正文、不循环。扫描线如使用，为静态极低对比纹理，避开正文、菜单、搜索和照片。光晕仅给装饰点，不给正文发光。无需持续降雪、鼠标尾迹、背景音乐或全屏颗粒漂移。

减少动态效果时取消平移、描线、扫描、平滑滚动和主题转场，直接呈现最终状态。离屏停止装饰动画，后台不运行连续动画；移动端降低网点与刻度密度，不做全屏模糊。无动画时所有功能必须成立。

## 10. 全站功能衔接与验收

搜索保留快捷键与正式结果跳转；浅色为纸面索引，深色为检索面板。参考样稿的模拟阅读窗口不能替换正式文章路由。归档、项目、专题和文章延续同一套字色边界，但正文保持干净，目录、公式、代码、图片放大、双链、概念及现有阅读能力全部保留。工具、简历、关于、友链、评论、订阅、RSS 和后台编辑同步能力不做功能删减，详见功能表。

后续实施验证 1440px、768px、390px 和 320px；覆盖浅深色、中英德长文本、200% 缩放、键盘、触屏、减少动态效果、空内容和大量内容。正文对比度至少 4.5:1，大字和必要非文字控件至少 3:1，触控目标建议至少 44px。旧链接、主题持久化、语言切换、搜索、教材、分组、精选和随记须回归。

本版建议审阅昼夜远征叙事、刊头与主峰比例、五章连续阅读节奏、星图辨识度与动画强度。文案和尺寸是设计建议，尚未写入页面代码。
