# 感知与偶然：六个在线小工具

## 目标与共同约定

在现有 Astro 工具列表中增加六个独立工具，延续“感知、偶然、留下痕迹”的主题。
不需要登录，计算、绘画、声音和文字均在浏览器本地运行。适配中文、英文、德文、
深浅色模式、鼠标、键盘和手机触摸。操作放在画面边缘，画布为主体。

可保存作品的工具导出 PNG，使用当前主题背景，仅包含作品。成绩只保留在当前页面访问中。
离开页面清理事件、动画与音频；切换应用时暂停模拟或中断反应挑战。

| 工具     | 路径                  | 主要体验                           |
| -------- | --------------------- | ---------------------------------- |
| 盲画圆   | `/tools/blind-circle` | 隐藏笔迹画圆，松手揭晓             |
| 引力     | `/tools/gravity`      | 发射小球、放置引力点，观察轨道     |
| 一瞬     | `/tools/reaction`     | 等待随机提示，测试五轮反应速度     |
| 余波     | `/tools/ripples`      | 点击、按住、拖动产生相互干涉的水波 |
| 听见颜色 | `/tools/color-music`  | 点击演奏、录制八秒旋律并循环       |
| 消失的字 | `/tools/fading-words` | 写字后让文字变成颗粒，留下或放走   |

## 1. 盲画圆

- 点击开始，按住鼠标或手指一笔画圆，绘制时隐藏轨迹，松手揭晓。
- 展示原始笔迹和拟合参考圆。评分：圆润程度 60%、闭合程度 25%、完整程度 15%。
- 使用几何拟合，按圆半径归一化误差，不按位置、大小和绘画速度加分。
- 排除过短笔迹、过小点圈与明显不完整的圆弧；异常笔迹提示重画。
- 显示本页尝试次数和最佳成绩，提供再画一次和保存图片。

## 2. 引力

- 空白处拖动松手发射小球，方向和拖动距离决定初速度；发射前显示方向预览。
- 空白处轻点创建引力点，拖动已有引力点调整位置；选中后调整强度或删除。
- 无引力时直线运动；画布边缘反弹；小球相互碰撞后反弹。
- 引力中心软化处理，设置速度上限、对象数量上限（60 球、8 引力点）。
- 绘制逐渐淡去的轨道，提供暂停、轨迹开关、清空、保存；空格暂停。

## 3. 一瞬

- 主动开始每一轮，随机等待 1.5–5 秒后出现光与“现在！”文字。
- 点击画面或按空格响应；抢跑不计成绩，重试当前轮。
- 在绘制提示的动画帧记录起点；不自动连续闪烁。
- 五次有效反应组成一组，展示全部用时、中位成绩与最快成绩。
- 切换应用或标签页使当前轮作废，返回后手动重新开始。

## 4. 余波

- 点击产生涟漪、按住持续扰动、拖动沿路径产生波纹，波纹发生叠加和干涉。
- 采用有阻尼的二维水波网格；浅色为清水，深色为夜间水面。
- 初始平静，停止交互后逐渐恢复平静；根据画布尺寸限制模拟分辨率。
- 轻柔／清晰两档强度，暂停、恢复平静、保存图片；暂停时可导出当前纹理。

## 5. 听见颜色

- 横向映射五声音阶音高，纵向映射音色明亮程度；音符伴随对应颜色光点。
- 点击演奏，拖动按间隔触发音符，限制复音和音量避免突发过响。
- 用户点击后才启用 Web Audio；支持音量和静音，无音频支持时给出提示。
- 主动录制 8 秒音符，显示进度，记录相对触发时间；结束后循环播放并同步光点。
- 停止循环、重新录制、清空。后台暂停播放，回来手动继续。
- 第一版不提供音频文件导出。

## 6. 消失的字

- 输入停止 3 秒后提示“继续写，或让它飘走”，再等 2 秒文字化成颗粒消散。
- 消散前输入会取消倒计时；输入法组词期间不计时。
- 消散过程中“继续写”恢复本次原文；“留下”停止自动消散；“放走”立即消散。
- 消散完成返回空白。保存图片可导出文字或当前颗粒，另有重新开始。
- 文本仅保存在本页内存，不上传、不写入 localStorage；减少动态效果时使用淡出。

## 实现结构与验收

共享工具目录、页面外壳、画布尺寸与主题处理、PNG 导出和事件清理；每个工具使用
独立行为模块，按页面加载。几何评分、碰撞和水波等可单测逻辑放入 `src/lib/tools`。
复用现有 Astro `ToolPage` 和三语路由结构，不新增服务端接口或依赖。

按“盲画圆／一瞬 → 引力／余波 → 听见颜色／消失的字”完成，并接入工具列表。
验收覆盖计算单测、桌面浏览器真实交互、手机触摸、主题切换、后台切换、图片导出、
音频生命周期、中文输入法事件，以及 Astro 类型检查和生产构建。
