# 第二组互动小工具

沿用现有 PlayWorkbench、三语路由和浏览器本地运行方式，加入以下六个工具。

| 工具     | 路径                   | 功能                                                                         |
| -------- | ---------------------- | ---------------------------------------------------------------------------- |
| 叠石     | `/tools/stack-stones`  | 拖动不同形状与重量的石头，重力、旋转、摩擦和碰撞；最高纪录、暂停、换石、保存 |
| 记一眼   | `/tools/visual-memory` | 短暂显示光点，隐藏后点击原位置，按最优对应计算偏差；逐轮增加光点             |
| 辨色     | `/tools/color-sense`   | 找出色块中略有不同的一块，难度递增；不限时与 30 秒挑战，键盘选择             |
| 折光     | `/tools/refraction`    | 移动、旋转棱镜、镜面和光源，反射、Snell 折射及色散；自由模式和照亮目标关卡   |
| 雪迹     | `/tools/snow-trails`   | WASD、点击或拖动引导行走，留下左右脚印；风向、降雪、暂停、停雪保留图案与导出 |
| 连成星座 | `/tools/constellation` | 随机星空、连线、撤销、命名、注释、日期星图卡片；种子与 URL 重现星空          |

共同支持鼠标、手机触摸、深浅色模式、中文／英文／德文。成绩保留在当前页，
不新增服务端接口、不上传用户文字。活动模拟在后台暂停；记忆／计时挑战中断不计分。
星座的 URL 仅存星空种子，不包含名称和注释。图片导出使用当前主题，排除操作控件。

叠石采用凸多边形刚体与冲量碰撞，限制石头总数，使用固定步长维持稳定；
折光采用有次数上限的二维几何光线追踪，不模拟波动光学。
