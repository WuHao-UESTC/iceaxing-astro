# 写作中的概念

在正文编辑器左侧展开“概念”，可按名称查找。选中概念后点击顶部“插入链接”，或在查找框按上下键选择、Enter 插入。

新建时先选中正文，点击“新建”，填写名称并保存。原文及其格式保持不变，只添加一对概念边界标记。使用工作区原有的“保存”保存笔记后，概念才会进入其他笔记的查找列表。未保存的新概念只属于当前编辑会话。

正文里的概念链接悬浮时显示定义；触屏或键盘可点击/聚焦查看。通过“查看原文”跳转至来源文字。同一笔记直接选中原文；其他笔记会在新标签页的工作区中打开并选中原文，保留当前未保存的写作内容。阅读页使用高亮显示，只展示可公开访问的来源定义，草稿来源显示为未解析文字。

概念定义直接读取来源标记之间的当前文字，因此修改来源后无需再维护一份定义。请保留起点和终点标记，移动概念时把两端与原文一起移动；复制后应重新新建概念，避免重复身份。删除任意一端后，该定义不再进入查找目录，已有链接会显示为失效。

此功能没有独立概念栏目、同步定义块或副本模式。工具面板和名称列表采用透明无框样式，沿用工作区的主题变量；窄屏可收起。
