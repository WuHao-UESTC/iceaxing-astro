# 工作区发布状态与 Obsidian 同步

分类、项目、合集的“发布状态”位于属性第 03 区，与精选、排序、创建时间同排。项目原有的计划中、进行中、已完成等状态仍用于项目进度。

- 新建层级默认草稿；缺少发布字段的旧内容按已发布兼容。
- 分类 → 项目 → 合集 → 文章必须满足整条上级链公开，下级才能公开。上级关闭不会改写下级自己保存的状态，文件树会标记“上级未发布”。
- 选择定时发布后填写发布时间。定时公开沿用文章现有的构建/刷新机制：到达时间后，下次构建或“刷新预览”会更新公开路由；没有额外添加部署定时器。
- 未公开层级及其下级不会进入公开路由、首页、订阅列表或发布清单。

## 使用同步

1. 使用桌面版 Chrome 或 Edge 打开工作区，页面需为 HTTPS 或 localhost。
2. 先保存文章。在文件树底部展开“Obsidian 同步”，选择仓库根目录并允许写入。
3. 点击“同步全部文章”。同步包含当前来源/分支下的中文、英文、德文文章，包括草稿，不受当前 group 限制。

目录句柄存于当前站点、当前浏览器的 IndexedDB。刷新后会恢复目录；浏览器若要求重新授权，点击同步后允许即可。网页不会读取或保存完整磁盘路径。更换浏览器、站点地址或清理站点数据后需重新选择。

## 仓库内结构

```text
所选目录/
  iceaxing-astro/
    zh/（en、de 同样组织）
      技术栈/（或学习笔记、生活日常）
        分类名/
          分类的独立文章.md
          项目名/
            项目的独立文章.md
            合集名/
              文章标题.md
      未归类/
    附件/
    .sources/<语言>/<稳定内容 ID>.mdoc
    .keystatic-sync.json
```

Markdown 保留 YAML 属性，标题作为 Obsidian alias。公式转换为 `$…$` / `$$…$$`，双链使用仓库内路径；本地图片和 PDF 复制到附件目录，远程 URL 保留为原链接。提示框和折叠块转换为 Obsidian callout，分栏转换为顺序内容，思维导图保留源文本。原始 Markdoc 另存于隐藏的 `.sources` 中。

分类、项目和合集使用对应语言的名称，缺少翻译时回退中文名称或稳定 ID，空文件夹也会保留。文章按照自身的合集、项目或分类归属放置，未指定归属或上级缺失时放入“未归类”。文件名中的非法字符会替换，重名时追加稳定 ID。

旧版 `Keystatic/` 目录不自动移动或删除；首次使用新结构会在 `iceaxing-astro/` 中重新导出。改名或移动后的旧笔记也会保留。

重复同步只更新有同步记录且未被本地修改的文件。对 Obsidian 内自行修改的笔记或已有的非托管文件，保留原文件并列出冲突，不自动覆盖。不会删除 Obsidian 笔记，也不会反向修改 Keystatic。处理冲突时，可将所需更改手动合入 Keystatic 后重新同步。

本地工作区从磁盘读取已保存内容；线上 GitHub 工作区需要先登录 Keystatic，导出使用当前分支的文件快照。GitHub 凭证只在服务端使用，私有文章和附件不通过公开静态清单导出。
