# 概念组件 · 精简审阅版

本轮重构已有 HTML 审阅样稿，尚未接入真实编辑器或内容存储。此版本取代此前包含概念管理页的完整方案。

## 当前范围

1. **左侧浮动**：作为写作页面上的轻量工具，透明背景，无边框、阴影或独立栏目的分隔线；采用浮层定位，不增加固定侧栏。可收起。
2. **查找概念**：搜索名称和别名。保留键盘上下选择、Enter 插入、无结果提示。
3. **紧凑列表**：每行仅有概念名称，不显示摘要、别名、分类、收藏或定义；桌面行高约 27px，以文字颜色与小圆点表示选中。
4. **顶部插入**：“插入链接”位于浮动组件最上方，没有匹配项时禁用。
5. **统一链接**：仅在正文光标位置插入概念名链接，操作浮动面板后保留此前正文选择；移除同步定义、副本、插入模式选项。
6. **悬浮卡片**：鼠标停留在正文链接上显示名称、定义与“查看原文”。移入卡片后保持显示，离开后关闭。卡片无框、无阴影，使用轻微半透明底色保障覆盖文字时的可读性。
7. **原文定位**：从卡片跳至来源文字并高亮，可返回写作。原型展示示例摘录，正式接入应使用文章 ID + 片段 ID。
8. **新建概念**：选中正文文字，点击顶部“新建”，只填写概念名称。所选文字自动作为定义，保存后加入名称列表并选中；保留原文，后续仍使用“插入链接”。输入区沿用透明无框样式，支持取消和同名提示。

## 已移除

独立概念管理栏目、完整管理表单、同步定义、独立副本、自定义显示文字、分类筛选、标签、收藏、最近使用、归档、版本、反向引用、来源变化模拟。仅保留选中文字后填写名称的轻量新建流程。

已有定义由内容数据提供，新建定义直接来自所选原文。正式接入时衔接现有内容存储方式，不增加专门管理栏目。原型新建概念只在当前演示会话中有效。

## 风格与适配

- 沿用现有工作区的纸面色、绿色强调、衬线正文和无衬线工具文字，适配深浅主题。
- 浮动工具、搜索框、名称按钮均为透明无框；概念链接使用细下划线。
- 窄屏仍在左侧浮动，放于正文上方留白，避免重叠；触屏可点击正文链接查看卡片。
- 支持键盘聚焦显示概念卡片、Escape 关闭。

## 审阅路径

搜索概念 → 在正文放置光标 → 选择概念 → 点击顶部“插入链接” → 悬浮查看卡片 → 查看原文。

新建：选中正文文字 → 顶部“新建” → 填写名称并保存 → 在列表中查找和插入。保存不会将整段原文替换为概念名称。
