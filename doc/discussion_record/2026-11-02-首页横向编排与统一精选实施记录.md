- 桌面章节使用扣除全站导航后的可视高度，左侧山脊路线固定，右侧章节完成翻页后整章停靠。

## 精选浏览与动画

精选在支持精细指针的桌面环境下缓慢整体向下移动；当前起稿参数为首次等待约 2.2 秒、约 9px/秒。鼠标进入或键盘焦点进入即暂停，未进入手动模式时离开后至少等待约 1.8 秒再恢复。用户主动滚动、触摸或拖动浏览后停止自动移动，浏览器返回时恢复位置与手动状态；状态在当前标签页会话中保存。

没有常驻暂停按钮。到达列表末尾停留，不无限循环、不触发翻章。手机、减少动态效果、后台标签页和非封面章节不运行精选自动滚动。

雪风转场将正文块轻移淡出，以少量墨点 / 琥珀风雪线连接下一章；章号标题先于后续元素建立。当前主要过程约 480ms，左右方向跟随前进 / 返回，左侧路线不被吹走。快速连续点击取消旧转场，以最新目标为准；低动态模式直接停靠。

以上数值为本轮实现参数，可在后续审阅中调整，不追加为已经确认、不可更改的设计要求。

## Keystatic 统一精选

文章、项目、分类、合集统一使用原有 `featured` 与新增 `featuredOrder`。详情表单统一标为“是否精选”“精选顺序”；目录自身的 `order` 继续独立工作。已有精选勾选保留，未设置精选顺序的内容使用同一默认值及稳定的类型 / ID 次序，不自动新增推荐。

后台入口：`/keystatic/workspace` 顶部“首页精选 · 编排”，或侧栏“其他内容 → 首页精选 · 统一排序”。

精选页默认列出已精选项，可查看未精选内容、查找并勾选。支持拖动和上移 / 下移，显式保存；显示类型、语言、发布状态、未公开原因和可用的预览 / 编辑入口。文章语言版本各自保存推荐状态与顺序；分类、项目、合集沿用共享多语言记录，与前台共同排序。

前台按当前语言、公开状态和父级公开规则过滤，再按精选顺序展示。草稿、未公开父级下的内容保留在后台，不能在首页留下空卡片。原有合集数量为零，合集支持通过测试数据验证，没有为演示新建正式合集。

详情页与列表页读写同一份内容字段。列表存在未保存调整时，暂不进入详情编辑；切换管理视图保留未保存编排，重新进入且没有未保存调整时读取最新数据。保存比较内容版本，发现其他修改时返回冲突，要求重新加载，避免静默覆盖。切换 GitHub 分支时重新加载对应分支，迟到的读取 / 保存结果不能覆盖当前分支视图。

本地写入只在开发环境开放，只更新精选字段，保留正文；同一进程串行处理并做版本检查，失败时尽力回滚本批已写文件。GitHub 模式沿用登录令牌、当前分支和 pathPrefix，以 expectedHeadOid 检查将修改作为一个提交保存。实际 GitHub 远程写入本轮没有执行；协议通过模拟测试验证。外部改动造成的冲突不能强行覆盖。
