## 功能保留表

| 既有能力 | 新外观承接 | 后续验证重点 |
| --- | --- | --- |
| 欢迎页、简历 / 博客双入口 | 远征邀请与观测站入口 | 三语言路由、新标签、返回 |
| 头像、姓名、简介、座右铭 | 沿用当前内容源 | 缺省值、长文本、署名 |
| 封面与四板块、章间导航 | 五章保留，刊物 / 仪表章节 | 旧锚点、直达、滚动、前进后退 |
| 精选切换、推荐目的地、归档入口 | 本期选读及路线目录 | 顺序、手动切换、空列表、所有目标可达 |
| 技术分类与实践项目、状态、进度 | 岩脊工坊与项目记录表 | 实际百分比、分类规则、项目路由 |
| 教材星图、聚焦、返回、文章、计数、近期笔记 | 观测星图加文字索引 | 全景 / 选择 / 返回、键盘、空状态 |
| 生活分组、切换、近期内容 | 生活版与档案窗 | 分组归属、无分类、无文章 |
| 碎碎念、展开、归档、站内目的地 | 短讯与通信日志 | 时间顺序、全文、关于 / 工具 / 友链可达 |
| 导航、移动菜单、主题、语言 | 同功能新材质 | 当前页、焦点、主题持久化、三语言切换 |
| 搜索与快捷键 | 纸面索引 / 终端检索 | Ctrl / Command K、斜杠、Escape、焦点归还、正式结果跳转 |
| 分类、项目、系列与文章归档 | 沿用数据关系和路由 | 既有筛选、排序、分页及公开范围 |
| 正文、目录、公式、代码、媒体与图片查看 | 干净阅读面 | 定位、溢出、图片原色与放大 |
| 双链、概念与内容关系等阅读能力 | 原入口保留 | 目标、展开与关联内容 |
| 评论、订阅、RSS | 原流程换视觉 | 输入、提交、反馈及现有退订流程 |
| 简历、项目经历、证书、画廊、关于、友链 | 内容和操作保留，后续套用视觉规范 | 长页、图片查看、外链 |
| 工具目录、已有小游戏与交互工具 | 全部保留，允许必要专用色 | 每个现有工具回归，不能为双色化损害读数 |
| Keystatic、发布状态、媒体、Obsidian 同步 | 后台与数据协议不变 | 不因视觉改造删除或重构能力 |
| 无障碍、响应式和旧链接兼容 | 重构约束 | 键盘、触屏、缩放、低动态及路由 |

“保留全部功能”还要求实施前按正式路由与组件补齐逐项基线，不能以此表未点名为由删去能力。两页提案不意味着本轮扩大为全站实施。
