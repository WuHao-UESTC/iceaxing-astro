# Iceaxing · 五种设计方向

直接打开 `index.html` 对比，或分别打开 `a.html` 至 `e.html`。无需安装依赖、构建或联网。正式站点没有应用这些修改。

| 方案 | 视觉设计 | 精选交互 |
| --- | --- | --- |
| A 雪线编辑部 | 冷白、松绿、杂志式层级、横幅山景 | 交叉溶解与文字轻移 |
| B 夜航观测站 | 深蓝、琥珀、星空与观测轨道 | 观测窗切换与轨道旋转 |
| C 山野手札 | 纸张肌理、苔绿、陶土红、不规则纸页 | 平移与轻微旋转翻页 |
| D 工程图谱 | 钴蓝、坐标网格、模块化双列文章 | 水平滑轨与编号索引 |
| E 极简远山 | 米白、墨绿、留白、山水层次 | 远山溶解与标题柔和显隐 |

每版包含完整首页、三组精选、四篇文章示意、主题筛选、搜索、关于与学习路线窗口、文章阅读排版、专题入口和页脚。轮播支持左右按钮、编号、键盘左右键、触摸横滑；默认手动，主动开启后每 6.5 秒切换，悬停、焦点、后台和弹窗期间暂停。遵循系统减少动态效果设置。

文章标题取材于项目主题，摘要与阅读窗口正文是排版示意，不是对正式文章的替换。所有图像由本地可编辑 SVG 绘制，无远程素材和字体请求。字体使用系统字体，设备间字形会略有差异。

修改 `styles.css` 和 `preview.js` 可直接查看效果；`build.mjs` 生成 HTML，重新执行 `node doc/prototypes/blog-directions/build.mjs` 会覆盖本目录下生成的五个页面、对比入口与内容清单。

建议先比较 1440px 桌面与 390px 手机效果，再决定方向。样稿展示的色彩、间距、插画和动效均由实际 HTML/CSS/JS 实现，可迁移至 Astro；正式接入时还需使用真实内容复核长标题、长列表、深浅主题和性能。
