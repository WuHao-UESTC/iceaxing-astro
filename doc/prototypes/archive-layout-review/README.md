# 分类、项目与合集：五种侧栏替代方案

直接用浏览器打开 [index.html](index.html)，再进入五个方案。文件均为本地 HTML、CSS、JavaScript 和图片，无需启动 Astro。

| 方案                   | 核心变化                               | 更适合                   |
| ---------------------- | -------------------------------------- | ------------------------ |
| [A 通栏书页](a.html)   | 完全取消侧栏，分组与条目展开到整页     | 当前内容量、直接浏览     |
| [B 横向切换](b.html)   | 顶部标签按内容类型筛选，滚动时保持可用 | 分类与项目的混合内容     |
| [C 阅读起点](c.html)   | 首项作为开篇入口，其余条目继续展开     | 教材与连续专题           |
| [D 沿途路径](d.html)   | 将日期、状态与章节节点融进条目边缘     | 长期项目、旅行和顺序阅读 |
| [E 筛选工作台](e.html) | 侧栏改为搜索、类型、主题和状态筛选     | 条目较多的目录           |

每版顶部可切换四种栏目配色、分类/项目/合集、内容量和浅深色。点击“查看布局”可直接跳到目录区域。方案间切换会保留当前设置。

B 的类型筛选、E 的搜索与筛选均可操作；E 在手机端默认收起筛选区。点击条目可打开示意预览，关闭按钮、空白处和 Escape 均可关闭。

C 的首项不在后续列表重复。所有方案均保留合集原有章节次序，C 与 E 中的章节编号也沿用原次序。普通文章条目继续使用统一高度，序号与封面不重叠。

页面标题及部分条目取自现有内容；合集、扩展条目与部分专题归属用于设计演示，已在页面提示。未修改正式组件、内容文件或 Keystatic。

## 维护与检查

在项目根目录执行：

```sh
node doc/prototypes/archive-layout-review/generate.mjs
node doc/prototypes/archive-layout-review/check.mjs
```

生成脚本会复制当前列表和标题区 CSS，以及项目已有封面素材。检查脚本使用本机 Edge 验证 510 组布局组合，并检查筛选、搜索、重置、手机端展开、条目预览及控制项，截图保存在本目录。
