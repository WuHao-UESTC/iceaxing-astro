目录之外 / 分类 · 项目 · 合集

把空间还给内容。

左侧目录只有一两个入口时，确实不值得长期占用一列。这里准备了四种取消侧栏的方式，以及一种将侧栏改为真正筛选工具的方式。

建议先看 A，再比较 B

A 最直接，也最适合现在的内容量；B 为混合内容增加切换能力。C 偏重阅读起点，D 偏重沿途的叙事，E 留给内容明显增多之后。

A / 通栏书页

取消侧栏，让内容完整展开

直接去掉左侧目录，用完整页宽呈现项目、合集与文章。分组标题仍然清晰，条目之间保留呼吸感。

内容较少、以浏览为主；改动最少。打开交互样稿 ↗

B / 横向切换

目录变成可操作的内容标签

取消侧栏，把内容类型放到顶部横向标签中。标签用于筛选，滚动后仍能切换；只有一种类型时自动简化。

项目、合集、文章混合出现的分类与项目页面。打开交互样稿 ↗

C / 阅读起点

先给一个入口，再展开目录

取消侧栏，把现有排序中的第一个项目、合集或章节提到开篇，其余内容继续向下展开。第一步更明确。

教材笔记、连续专题与有固定阅读顺序的合集。打开交互样稿 ↗

D / 沿途路径

把日期与章节顺序融进条目

取消独立侧栏，用一条纤细的路径串联分组和条目。日期、项目状态或章节次序成为沿途节点。

长期项目、旅行手记、逐步推进的章节目录。打开交互样稿 ↗

E / 筛选工作台

保留侧栏，但让它真正处理内容

将目录换成搜索、内容类型和主题筛选。结果数量即时变化；手机端收成可展开的筛选区域。

二十条以上，或标签与内容类型较多的分类。打开交互样稿 ↗
五版差别
方案 原侧栏的位置 新增价值 适用情况
A 通栏书页 完全取消 更宽、更直接的浏览空间 少量至中等条目
B 横向切换 顶部标签 按内容类型筛选，可随滚动操作 分类与项目的混合内容
C 阅读起点 完全取消 明确第一步，不重复展示首项 教材与连续专题
D 沿途路径 融入条目边缘 日期、状态与章节节点形成节奏 项目记录与有顺序的合集
E 筛选工作台 改为筛选工具 标题搜索、类型和主题筛选 条目较多的目录

每版可切换 4 种栏目配色、3 种页面层级、4 种内容量和浅深色。标题区沿用当前透明背景、大封面和紧凑高度；文章条目仍使用固定高度。合集始终保留既定章节顺序。
