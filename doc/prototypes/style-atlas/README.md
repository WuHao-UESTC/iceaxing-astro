# Iceaxing · 十五种美术语言

打开 [index.html](index.html) 比较十五版。每版可单独打开，不需要启动 Astro、安装依赖或联网。

## 交付

- 三轮各五版，十五个 HTML，每版五个独立切换的章节，共七十五个章节画面。
- 保留封面、技术栈、学习笔记、生活日常、沿途随记及原章节锚点。
- 教材选择／笔记预览，生活分组，随记时间线，搜索，文章阅读窗口。
- 所有美术插画为原创可编辑 SVG；图像、卡片外观、构图和章节转场分别设计。
- [十五版封面总览](all-15-styles.png)；每版入口内附五章节桌面与手机对照图。
- [三轮参考来源](research/index.html)；第二、三轮调研报告分别在 `research/round-2.md` 和 `research/round-3.md`。

## 内容和逻辑

分类、教材、项目和可用文章摘录读取当前仓库。选取八篇正文有实际内容的公开文章用于排版检查；短记及部分说明为示意，已在页面中标注。内容索引和导航窗口是本地交互演示；没有改动正式数据或生产路由。

章节可通过顶部五项导航、下方前后按钮、PageUp／PageDown 切换；直接链接章节锚点与浏览器前进／后退也保留。轮播／分组为手动操作，未添加自动跳章。系统设置为减少动态效果时取消转场。

## 验证

使用现有 Playwright CLI 与 Edge 检查 1440px 桌面、390px 手机下的全部五章节，保存一百五十张章节截图；另有十五张阅读窗口截图、十五张章节对照图和一张总览。

功能覆盖：教材切换及目录、生活分组及打开、时间线展开、搜索及打开正文、减少动态效果。检查记录在各轮 `*-check.txt`。首轮早期记录含两个溢出失败，后续 `round-1-fixes.txt` 修复验证；最终统一检查记录在 `final-review.txt`。

本地截图与实际 HTML 使用同一套代码。系统字体会随设备略有不同；样稿不等于已集成到正式 Astro 组件。选定风格后需按实际内容数量、深浅主题和正式路由完成接入。

## 文件

- `catalog.mjs`：十五版主题、配色、研究来源。
- `art.mjs`：原创插画。
- `base.css`：内容与交互基础。
- `themes.css`、`round2.css`、`round3.css`、`refinements.css`：分别设计的外观与转场。
- `app.js`：五章节、教材、生活组、搜索和阅读交互。
- `build.mjs`：读取项目内容，生成页面、插画和入口；执行 `node doc/prototypes/style-atlas/build.mjs`。
- `package-review.mjs`：用已有 Sharp 打包实际截图对照图；执行 `node doc/prototypes/style-atlas/package-review.mjs`。

本轮只新增独立样稿与研究材料，未应用到正式站点。
