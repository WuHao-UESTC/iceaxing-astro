# 学习笔记：教材分类与星图方案

## 已实施：教材作为一级分类

- 七本教材由 project 提升为 category，文章直接关联教材 category。
- 学习笔记首页直接展示七个教材分类；删除 uestc-note 大分类，analog-ic 只保留技术实践项目。
- 保留教材与文章稳定 ID，分类地址由 `/旧大分类/教材` 简化为 `/教材`，文章地址为 `/教材/文章`。
- 旧地址使用 301 跳转；旧教材项目与大分类订阅在匹配时兼容新教材分类，无需修改线上订阅数据。
- 迁移映射保存在 `src/data/study-migration.json`。此文件只记录已迁移内容，不作为未来星图的分类来源。

## 已实施：星空构图

首次进入显示完整星图：40 个固定、疏密有序的星位，当前七个教材分类点亮七颗，其余为暗星。亮星代表已有分类，与笔记数量无关；没有文章的分类仍可选中。暗星只作装饰，不可点击。

每颗亮星下方显示完整分类标题，长标题自然换行，悬停或键盘聚焦补充笔记数。星位与稳定分类 ID 绑定，排序或刷新不会让原有星星漂移。超过 40 个分类时扩展星位，避免隐藏内容。

点击亮星进入聚焦态：保持完整星图画布的原始尺寸，将选中星附近的一块平移到桌面左侧约 45% 区域，通过裁切隐藏其他部分；右侧淡入教材全名、简介、文章数量和文章列表，提供“打开分类”和“返回星图”。不缩放画布，也不随裁切窗口变窄而拉伸 SVG。平移过渡约 240ms，切换教材时只更新裁切位置与列表。

手机端使用上方精简星图、下方条目列表，避免把窄屏硬切成左右两栏。返回全图、键盘操作与减少动态效果均有对应行为；不接管首页滚轮，不改变已有章节锚点。

配色延续松石绿识别色，页面沿用全站纯色底，不使用渐变、星云和星图边框。星星以亮度区分分类星与背景星，不增加圆环；右下角保留多层山脊与等高线线稿，其余留白作为天空。保留章节标记和标题体系。

## Astro 实现边界

- Astro 在构建时读取教材分类与公开文章，输出 SVG 星图、真实分类链接及 HTML 文章列表；首页继续预渲染。
- 使用组件局部的原生 TypeScript 控制选择、列表切换与 CSS transform / opacity 动画，不新增框架运行时或 WebGL 依赖。
- 分类链接在无 JavaScript 时直接进入对应分类页；增强脚本就绪后才拦截点击并打开星图聚焦态。完整内容仍由独立分类页提供。
- 初期数据量很小，可预渲染各教材的近期文章片段，点击无需请求接口；后续每类只展示固定数量，再通过分类页阅读全部。
- 首次进入章节后才启动少量星光动效；离开暂停，减少动态效果时直接切换布局。不使用持续运行的逐帧 JavaScript 绘制。
- 亮星提供至少 44px 点击区域、可见焦点、完整可访问名称；装饰星不进入键盘顺序。列表切换后明确标记选中分类。

星图是内容的导航增强层；分类、文章、搜索索引和普通链接保持独立可用。

## 实现记录

- `StudyTerrace.astro` 构建 SVG 星图、七个分类的 HTML 文章面板和真实分类链接，当前为七颗亮星与 33 颗装饰星。
- `study-constellation.ts` 模型以稳定教材 ID 确定星位；原有教材固定位置，新增分类按 ID 散列获得独立位置，不移动已有星位，也不限制分类数量。
- 同名脚本负责原尺寸平移裁切、分类切换、返回与 Escape，支持键盘 Enter 选中后聚焦文章面板标题；观察容器尺寸以适配窗口变化。
- 桌面聚焦时约 45% 星图、55% 列表；手机上图下文。局部裁切的其他星星可通过教材选择框切换。
- 动画期间固定桌面星图区高度，避免文章面板在展开过程中反复换行使章节高度跳动。分类文章最多预渲染八篇，完整内容通过分类页访问。
- 深浅主题、减少动态效果、离屏暂停星光、无 JavaScript 分类导航均已实现。现有首页章节锚点不变。
- Keystatic 分类的“首页板块”提供技术栈、学习笔记、生活日常三个选项。学习分类使用 `group: study`，七个教材已完成迁移，不使用标签控制板块归属。
- 学习分类、其项目/合集及文章按归属继承 `study` 场景，在深浅主题下分别使用浅青绿和深松石绿，避免继续继承技术栈的蓝色。
- 山体扩大至约七成视口高度，以右下角主峰、远中近色块和明暗切面呼应其他首页章节。星点沿标题与山脊之间的异形留白分布，背景星采用候选点间距采样，减少聚集。
- 星网以最小生成树保证整体连通，再按距离为星星增加最近四个邻点之间的连接；加入前排除交叉连线，构成网格与环路。当前 40 颗星共 87 条连线，其中 39 颗至少连接三颗邻星。连线仅在至少一端直接连接亮星时点亮，两端均为暗星时保持暗色，不沿路径传播。选中教材时进一步强调其直接邻线，已通过无交叉、连通性、邻接数量和点亮规则测试。
- 完整标题在桌面最多约 14rem 宽度内换行，手机加高星空区以容纳标题，聚焦后选中教材标题使用更宽的文本区域。
