分析一个电路时，我们常常需要判断它是否稳定。一个直观的出发点，是观察输入与输出之间的关系。

当我们说一个系统具有 BIBO 稳定性 时，关注的是有界输入是否始终对应有界输出。

对于连续时间线性时不变系统，还可以通过 冲激响应 的绝对可积性来判断这一性质。
